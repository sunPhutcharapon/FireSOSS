# 🚨 FireSOSS - แอปพลิเคชันแจ้งเหตุอัคคีภัยฉุกเฉิน (Emergency Fire SOS App)

**FireSOSS** คือแอปพลิเคชันมือถือบนระบบปฏิบัติการ Android สำหรับช่วยเหลือและแจ้งเหตุอัคคีภัยฉุกเฉินอย่างเร่งด่วน พัฒนาด้วย **Flutter (Material 3)** ช่วยระบุพิกัด GPS ของผู้ใช้งาน โทรแจ้งสายด่วนดับเพลิงทันที ส่ง SMS พิกัดสถานที่เกิดเหตุไปยังผู้ติดต่อฉุกเฉิน และค้นหาสถานีดับเพลิงที่ใกล้ที่สุดพร้อมระบบนำทาง

---

## 🌟 ฟีเจอร์หลัก (Key Features)

- 🚨 **ปุ่ม SOS ฉุกเฉินแบบเด่นชัด:**
  - ปุ่มแจ้งเหตุขนาดใหญ่พร้อมไฟแอนิเมชันแจ้งเตือน
  - ระบบป้องกันการกดพลาดด้วยหน้าต่างยืนยันก่อนดำเนินการ
  - ดึงตำแหน่งพิกัด GPS สดปัจจุบันอย่างแม่นยำ
- 📞 **ระบบโทรออกฉุกเฉินทันที (Direct Call):**
  - กดโทรหาเบอร์สายด่วนแจ้งเหตุ (`0960528206` / `199`) หรือสถานีดับเพลิงแล้ว **โทรออกให้อัตโนมัติทันที** โดยไม่ต้องเสียเวลากดปุ่มสีเขียวซ้ำบนแป้นพิมพ์
- 💬 **ส่ง SMS แจ้งพิกัดสถานที่เกิดเหตุ:**
  - สร้างข้อความขอความช่วยเหลืออัตโนมัติพร้อมแนบลิงก์ Google Maps ระบุพิกัด ส่งตรงไปยังรายชื่อผู้ติดต่อฉุกเฉิน
- 👥 **จัดการรายชื่อผู้ติดต่อฉุกเฉิน (Emergency Contacts):**
  - บันทึกชื่อและเบอร์โทรศัพท์ของบุคคลสำคัญ
  - สามารถเพิ่ม แก้ไข และลบรายชื่อได้ง่ายดาย พร้อมระบบบันทึกลงเครื่องอัตโนมัติ
- 📜 **บันทึกประวัติการแจ้งเหตุ (Emergency Logs):**
  - เก็บบันทึกวัน เวลา และพิกัดสถานที่ทุกครั้งที่มีการกด SOS
  - มีปุ่มเปิดดูตำแหน่งย้อนหลังบน Google Maps
- 🚒 **ค้นหาสถานีดับเพลิงใกล้ที่สุด (Nearby Fire Stations):**
  - เชื่อมต่อ GPS และดึงข้อมูลสถานีดับเพลิงจริงรอบตัวในรัศมี 100 กม. ผ่าน **OpenStreetMap (ฟรี)** หรือ **Google Places API**
  - แสดงป้ายระยะทางกิโลเมตรเรียงจากใกล้ไปไกล
  - มีปุ่ม **"นำทาง / ดูแผนที่"** เปิด Google Maps ตรงไปยังสถานีดับเพลิงนั้นๆ ได้ทันที
- 🎨 **ดีไซน์สวยงาม ทันสมัย (Modern UI/UX):**
  - ออกแบบด้วยสไตล์ Material 3 โทนสีขาวนวล-แดงฉุกเฉิน
  - ขอบการ์ดโค้งมน อ่านง่าย ปุ่มกดสะดวก เหมาะกับมือถือ Android ทุกขนาดหน้าจอ

## 🛠️ ขั้นตอนการติดตั้งและการตั้งค่า (Setup & Installation)

### 1. ความต้องการของระบบ (Prerequisites)
- **Flutter SDK:** Version >= 3.12.0
- **Dart SDK:** Version >= 3.0.0
- **Android Studio** / **VS Code** พร้อม Flutter Extensions
- **Android Device / Emulator:** Android OS 8.0 (API Level 26) ขึ้นไป

### 2. การติดตั้งโปรเจกต์
1. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วดาวน์โหลดแพ็กเกจที่จำเป็น:
   ```bash
   flutter pub get
   ```

2. (ตัวเลือกเสริม) การตั้งค่า **Google Maps API Key**:
   เปิดไฟล์ `lib/places_service.dart` และใส่ API Key ของคุณในบรรทัดที่ 8:
   ```dart
   const String googleApiKey = 'YOUR_GOOGLE_MAPS_API_KEY_HERE';
   ```
   *(หมายเหตุ: หากไม่ได้ใส่ API Key ระบบจะสลับไปใช้ **OpenStreetMap Overpass API ฟรี** โดยอัตโนมัติ)*

3. สั่งรันแอปพลิเคชัน:
   ```bash
   flutter run
   ```

## 📱 สิทธิ์การใช้งานบน Android (Android Permissions)

ไฟล์ `android/app/src/main/AndroidManifest.xml` ได้ทำการตั้งค่าสิทธิ์ที่จำเป็นไว้เรียบร้อยแล้ว:

- `ACCESS_FINE_LOCATION` & `ACCESS_COARSE_LOCATION` : สำหรับขอพิกัดละติจูด/ลองจิจูดจาก GPS
- `CALL_PHONE` : สำหรับโทรออกฉุกเฉินทันที
- `SEND_SMS` : สำหรับเปิดแอป SMS ส่งพิกัดสถานที่เกิดเหตุ
- `INTERNET` : สำหรับดึงข้อมูลสถานีดับเพลิงออนไลน์

## 📖 คู่มือการใช้งาน (User Guide)

1. **การแจ้งเหตุ SOS ฉุกเฉิน:**
   - เข้าหน้า **"หลัก"** กดปุ่ม **SOS** สีแดงขนาดใหญ่
   - กดปุ่ม **"ยืนยันแจ้งเหตุ"** บนป็อปอัป
   - แอปจะดึงตำแหน่ง GPS ปัจจุบัน บันทึกลงประวัติ และแสดงป็อปอัปตัวเลือก **"โทรแจ้งเหตุ"** หรือ **"ส่ง SMS"**

2. **การเพิ่มผู้ติดต่อฉุกเฉิน:**
   - เข้าหน้า **"ผู้ติดต่อ"** กดปุ่ม **"+ เพิ่ม"** มุมขวาบน
   - กรอกชื่อและเบอร์โทรศัพท์ แล้วกด **"บันทึกผู้ติดต่อ"**
   - สามารถกดไอคอน **โทร 📞** เพื่อโทรหาผู้ติดต่อได้ทันที หรือกด **ลบ 🗑️** เพื่อลบข้อมูล

3. **การค้นหาสถานีดับเพลิงและนำทาง:**
   - เข้าหน้า **"สถานี"** กดปุ่ม **"ค้นหาตำแหน่งฉัน"**
   - รายการสถานีดับเพลิงจริงในรัศมีใกล้เคียงจะแสดงขึ้นมาพร้อมระยะทาง (กม.)
   - กดที่การ์ดสถานีหรือไอคอน **นำทาง 🧭** เพื่อเปิด Google Maps นำทางไปยังสถานีนั้นๆ ทันที
